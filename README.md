* DESCRIÇÃO DA IMPLEMENTAÇÃO

O PROJETO FOI FOI FEITO EM JAVASCRIPT E NODE.JS UTILIZADO WEBSOCKET COMO PROTOCOLO DE COMUNICAÇÃO CONTÍNUA PARA FACILITAR A ENTREGA DO PROJETO E SUAS FUNCIONALIDADES ESPECÍFICAS SUGERIDAS.

UTILIZANDO O SOCKET, É GERADO UM ID PARA IDENTIFICAÇÃO DO USUÁRIO E CLIENTE.

FOI CRIADO UM ARQUIVO A PARTE (UTILS.JS) ARMAZENDO AS FUNÇÕES PARA A MELHOR ORGANIZAÇÃO E MANUTENÇÕES FUTURAS.

INICIALMENTE O CLIENTE PREENCHE SEUS DADOS DE ATENDIMENTO QUE SERÁ SALVO PARA UM FUTURO HITÓRICO. PARALELAMENTE O ATENDENTE (USUÁRIO), RECEBERÁ A MENSAGEM ONDE PODE RESPONDER SIMULTANEAMENTE SEM PRECISAR DAR REFRESH NA TELA.
